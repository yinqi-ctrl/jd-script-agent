# 数据运营 · 真实体验（EXP-009）

## 一、职业基本信息
- **职业是什么**：通过数据采集、清洗、分析，为业务优化提供可落地决策支持的岗位。
- **大众印象**：技术岗、高薪、越老越吃香、稳定。
- **实际工作定位**：一半是"取数工具人"，一半是"业务翻译"，能否摆脱取数取决于业务理解。

## 二、真实工作状态
- **日常工作内容**：写 SQL 取数、做清洗与看板、搭建/维护指标体系、出分析报告、配合增长做 AB 测试分析。
- **典型一天**：
  - 9:30 收业务方取数需求，写 SQL；
  - 11:00 维护 BI 看板，排查数据异常；
  - 14:00 出周报/专题分析；
  - 16:00 跟业务对齐结论，常被质疑"数据不准"。
- **高频任务**：取数、做表、搭指标、写分析报告。
- **常用工具**：SQL、Excel、BI（Tableau/帆软）、基础 Python。
- **工作压力来源**：需求多且急、背锅"数据不准"、业务不采纳、价值难量化。

## 三、从业者反馈
- **常见优点**：通用性强、转岗面广、相对规律、经验保值。
- **常见缺点**：易成取数工具人、背锅、价值难证明。
- **行业吐槽**："我是取数机""业务方说数据不准，其实是他不想听""同岗薪资差 18K"。
- **新人容易踩坑**：只会 SQL 不会业务；被动接需求不复盘；不懂把数据翻译成业务语言；以为高薪躺着拿。

## 四、职业认知差
- **大众以为**：高薪技术岗、越老越吃香、很稳定。
- **实际情况**：多数新人长期陷重复取数，薪资分化极大，价值要靠"翻译业务"才能体现。

## 五、视频创作价值
- **避坑类**：别当取数工具人，怎么破局。
- **揭秘类**：日常到底是取数还是分析。
- **对比类**：数据运营 vs 数据分析师，差在哪。
