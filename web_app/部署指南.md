# 部署指南：把本地应用变成"可分享的公开网址"

## 先搞清现状
- **现在**：`python app.py` 跑的是**本地服务**（`localhost:5000`），只有你这台电脑能开，别人点不开。
- **目标**：部署到云服务器，得到一个 `https://xxx.onrender.com` 公开网址，**谁点都能用**。

> 已为你提前改好部署要用的三处：
> 1. `kb.py` 知识库路径改成**相对路径**（不再写死 `d:/桌面/...`，云服务器是 Linux 找不到盘符）→ 已验证本地仍加载 91 文件。
> 2. `requirements.txt` 加了 `gunicorn`（云上要用生产级服务器，不能用 Flask 调试服务器）。
> 3. 新增 `Procfile`，告诉云平台怎么启动。

---

## 推荐方案：Render（免费、最简单、GitHub 一键连）

### 准备（5 分钟）
1. 注册 GitHub：https://github.com （已有就跳过）
2. 注册 Render：https://render.com （用 GitHub 登录最快）
3. 把项目推到 GitHub：
   - 在 GitHub 新建一个仓库（如 `jd-to-script-agent`）
   - 把 **整个 `智能体作业` 文件夹** 上传（必须包含 `web_app/` 和 `知识库/` 两个目录，知识库要跟着走）
   - 不会 git 命令的话，GitHub 网页端直接 "Add file" 拖文件夹也行（或用 GitHub Desktop）

### 在 Render 上部署（10 分钟）
1. Render 控制台 → **New** → **Web Service** → 连你的 GitHub 仓库
2. 配置：
   - **Runtime**：Python 3
   - **Build Command**：`pip install -r requirements.txt`
   - **Start Command**：`gunicorn app:app --bind 0.0.0.0:$PORT`
   - **Root Directory**：填 `web_app`（因为 app.py 在 web_app 里）
3. **Environment Variables**（关键！把 key 放服务器，别人看不到）：
   ```
   LLM_API_KEY=你的OpenRouter或硅基流动key
   LLM_BASE_URL=https://openrouter.ai/api/v1
   LLM_MODEL=google/gemma-3-4b-it
   TAVILY_API_KEY=你的tavilykey
   ```
4. 点 **Create Web Service**，等几分钟构建完，会给你一个 `https://xxx.onrender.com` 网址。

### ⚠️ 部署版的两个重要提醒
- **LLM 建议用 OpenRouter，别用硅基流动**：Render 服务器在海外，调 `api.siliconflow.cn`（国内服务）可能慢或被墙。OpenRouter 全球可用，最稳。你本地想用硅基流动随便，但**公开部署版换成 OpenRouter** 更保险（用 `google/gemma-3-4b-it`，便宜）。
- **公开网址 = 谁都能用、且会消耗你的 key 额度**：班级演示没问题；演示完可在 Render 把服务 **Pause**（暂停）或删掉，避免被人乱用烧钱。

## 备选方案：PythonAnywhere（不想用 git 时可考虑）
- 注册 https://www.pythonanywhere.com （免费版够用）
- 网页里把 `web_app` 和 `知识库` 两个文件夹上传
- 按它向导建 Flask 应用，指向 `app.py`
- 在 Dashboard 的 Environment 里设上面那 4 个环境变量
- 适合"不想碰 git"的同学，但免费版偶尔限流。

---

## 安全须知（必读）
- 你的 `LLM_API_KEY` / `TAVILY_API_KEY` 只存在**服务器环境变量**里，网页前端代码不会把 key 发给访客，所以别人看不到你的 key。
- 但公开网址意味着**任何拿到链接的人都能调用你的应用、消耗你的额度**。交作业/演示期间开着没问题，用完记得在平台暂停服务。

## 部署后自检
打开公开网址 → 贴一条 JD 生成 → 确认：
1. 底部「联网搜索：已启用」
2. 分数正确、标题等级一致
3. 时长 ≥80s（A级）/ ≥100s（S级）
4. 画面为"主播出镜 + 贴图/特效"风格

和本地跑的结果应完全一致（代码和知识库都上云了）。
