# 操作指南：从零跑通 Web 版智能体并交付作业

> 适用对象：Windows + PowerShell 用户，Python 3.12 已装。
> 目标：本地跑通 → 验证四个核心点 → 录屏/截图 →（可选）部署公开链接。
> 预计动手时间：本地版 2～3.5 小时（大头是等免费 Key）；公开链接版再 +1～2 小时。

---

## 开始前先确认三件事
1. Python 已装（你有 3.12，命令行输入 `python --version` 能看到版本号）。
2. 有一个能收验证码的邮箱（注册两家平台用）。
3. 网络能正常打开 https://open.bigmodel.cn 和 https://tavily.com。

## 步骤 1：拿 OpenRouter Key（约 10–20 分钟）
用途：生成脚本文案（OpenRouter 是 OpenAI 兼容接口，一个 key 能调几十个模型，含免费模型）。

1. 打开 https://openrouter.ai ，用邮箱 / Google / GitHub 注册登录。
2. 进 https://openrouter.ai/keys ，点「Create Key」，名称随便填（如 `my-agent`）。
3. 生成后**立刻复制**那一长串字符（形如 `sk-or-v1-xxxx`），存到记事本暂存。
   - Key 只此一面，关掉页面就看不到，务必先复制。
4. 账号默认带免费额度，直接用免费模型即可（无需充值）。推荐：
   - `google/gemma-2-9b-it`（免费，效果不错，默认就用它）
   - `meta-llama/llama-3.1-8b-instruct`（免费）
   - 想更强可换付费 `openai/gpt-4o-mini`（极便宜）。
   - 说明：部分 OpenRouter 免费模型不支持强制 JSON 输出，本项目已默认关闭该参数、用提示词 + 兜底解析，所以免费模型都能跑。

## 步骤 2：拿 Tavily Key（约 10–20 分钟）
用途：真·联网搜索（不拿也能跑，会自动降级为"知识库 + 模型自身知识"）。

1. 打开 https://tavily.com ，注册登录。
2. 进 Dashboard，找「API Keys」→「Create Key」。
3. 复制那一长串（形如 `tvly-xxxxxx`），存到记事本。
   - 免费额度足够班级演示。

## 步骤 3：安装依赖（约 5–15 分钟，看网速）
还是在 `web_app` 目录里：

```powershell

```

## 步骤 4：配置 .env（约 2 分钟）
把样例文件复制成真正的配置文件，再填入你的 Key。

**方法 A（命令行）**，在 `web_app` 目录：
```powershell
copy .env.example .env
```
> 如果 `copy` 报错，就直接在文件管理器里把 `.env.example` 复制一份、重命名为 `.env`（注意前面有个点）。

**方法 B（记事本）**：右键 `.env` → 用记事本打开，把这几行改成你刚复制的 Key：
```
LLM_API_KEY=这里粘贴你的OpenRouterKey
LLM_BASE_URL=https://openrouter.ai/api/v1
LLM_MODEL=google/gemma-2-9b-it
TAVILY_API_KEY=这里粘贴你的tavilykey
```
改完 **Ctrl+S 保存**并关闭。

> 不用改 `KB_DIR`（已默认指向 `d:/桌面/智能体作业/知识库`）和 `PORT`（默认 5000）。
> ⚠️ 安全：`.env` 里的 Key 只存在你本地，别提交到公开仓库、别在聊天里贴给别人。

## 步骤 7：对照核对四个核心点（必做，交作业底气）
拿这次结果逐项确认，这四件是你之前在 Coze 上反复翻车、现在用代码根治的：

| 核对项 | 怎么看 | 合格标准 |
|---|---|---|
| **① 分数算得对** | 看判定块综合分，自己按 `Σ(维度分×权重)×20` 手算一遍 | 例：上面这条 JD 应为 **89.0 / S**。代码算的不会错，你手算只是给自己安心 |
| **② 来源词干净** | 在页面里按 Ctrl+F 搜「来源」「知识库显示」「联网搜索显示」 | **搜出来应为 0**。脚本正文里不应有任何"来源：xxx"字样（来源只在核验表出现） |
| **③ 超范围拒答** | 另贴一条：`后端开发工程师` 或 `律师` 再点生成 | 应被直接拦截，返回"不在覆盖范围"，**不调模型、不生成脚本** |
| **④ 动态日期** | 看合规备注或核验表里的日期 | 应显示 **当天日期（2026-08-18）**，不是写死的旧日期 |

四项全过 = 核心逻辑稳了，可以放心交。

## 步骤 9（可选）：部署公开链接，让别人也能用
适合"发布给别人用"的要求。以 **Render** 为例（免费档）：

1. 把 `web_app` 整个文件夹推到你的 GitHub 仓库（**不要把 `.env` 传上去**，已在 `.gitignore` 思路里，手动注意）。
2. 打开 https://render.com 注册，连 GitHub。
3. 新建「Web Service」，选你的仓库。
   - Build Command：`pip install -r requirements.txt`
   - Start Command：`python app.py`
4. 在 Render 后台的 **Environment** 里手动添加这几个环境变量：
   - `LLM_API_KEY` = 你的 OpenRouter key
   - `LLM_BASE_URL` = `https://openrouter.ai/api/v1`
   - `LLM_MODEL` = `google/gemma-2-9b-it`
   - `TAVILY_API_KEY` = 你的 tavily key
   - （key 存在服务器环境变量，别人看不到）
5. 部署完成后 Render 给一个 `xxx.onrender.com` 公开网址，谁点开都能用。

> 免费额度够班级演示；如流量大再考虑付费。

## 常见问题速查（排错）

**Q1：`python` 不是内部或外部命令**
→ 用 `py app.py`；或把 Python 加进系统 PATH。

**Q2：pip install 很慢 / 超时**
→ 加镜像 `-i https://pypi.tuna.tsinghua.edu.cn/simple`。

**Q3：启动报 `ModuleNotFoundError: No module named 'flask'`**
→ 依赖没装好，重跑步骤 3；确认在 `web_app` 目录下执行。

**Q4：网页打不开 / 连不上 localhost:5000**
→ 确认步骤 5 的命令窗口还开着没关；看窗口有没有红色报错；端口被占用就改 `.env` 里的 `PORT=5001` 再重启。

**Q5：生成时报 OpenRouter 相关错误（如 401 / authentication）**
→ `.env` 里的 `LLM_API_KEY` 填错了或多了空格；或 `LLM_BASE_URL` 没写对（应是 `https://openrouter.ai/api/v1`），重新核对粘贴。

**Q6：生成时报 Tavily 错误**
→ `.env` 里的 `TAVILY_API_KEY` 有误；或先把它留空，系统会自动跳过联网只用语料库，不影响主流程。

**Q7：知识库读不到 / 检索为空**
→ 确认 `KB_DIR` 指向的路径 `d:/桌面/智能体作业/知识库` 真实存在且有 91 个 md。
