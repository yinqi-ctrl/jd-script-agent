# 这公司能去吗？新媒体运营5-8K：一人分饰十一绝的"六部尚书"

## 四、爆点 / 传播逻辑
- 爽点：替打工人把"画饼+压榨"翻成荒诞梗，发泄共鸣强。
- 信息差：识别"老板亲写JD""一人多岗"的方法可迁移。
- 记忆点梗："一人分饰十一绝""现代六部尚书""拼好班"。
- 情绪：愤怒→好笑→认同的过山车。

## 五、可复用套路（核心资产）
1. **"老板写JD"识别法**：JD 里混着招聘/人事/行政杂活 → 大概率是老板亲写，不专业、随意堆要求。
2. **"一人多岗"汇总法**：把 JD 里所有隐含岗位列出来加总（人事+文案+设计+运营+客服+编导+摄影+行政+助理+前台+司机），再对比薪资，制造"合起来反而更便宜"的反差爆点。
3. **钩子用极端强观点**："把仇人简历投过去"比"这工作坑不坑"更有点击欲。
4. **成本转嫁细节**：点出"剪辑会员费不报""开自己车办事"等，增强真实感与共鸣。
