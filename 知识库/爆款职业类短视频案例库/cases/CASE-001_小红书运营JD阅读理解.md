# 成都小红书运营JD阅读理解：6K"高薪"与"不下班"的真相

## 一、案例概要
- 来源：用户提供的小红书视频口播稿（BOSS直聘岗位，成都典型待遇）。
- 一句话：用"JD阅读理解"把官方招聘话术翻译成潜台词，站在打工人立场做避坑拆解，结尾反问引导互动。

## 二、选题与定位
- 目标岗位：小红书运营（成都，BOSS直聘）
- 行业 / 城市：新媒体运营 / 成都
- 选题角度：招聘 JD 避坑、潜台词翻译
- 受众：求职者（尤其应届、低门槛运营岗）、想入行运营的新人
- 钩子原文："这个是不是解过了啊 / 早上可以不上班什么意思啊 / 晚上可以不下班 / 可以不下班 / 这是一份boss上的岗位，还是属于成都这边比较典型的待遇"

## 三、内容结构拆解
| 段落 | 原文梗 / 要点 | 功能 |
|------|--------------|------|
| 1 开场钩子 | "早上可以不上班 / 晚上可以不下班" | 反差口语制造好奇，先抛离谱原话 |
| 2 交代来源与方法 | BOSS岗位、成都典型、原版JD杂→整理成"亮点/职责/福利"三部分 | 建立"帮你读JD"的人设与方法感 |
| 3 亮点反推 | ①高薪6-11K→薪酬范围公式：取最小值=6K，无区间=6K，"高薪成都合理" ②老板帅气好说话都是年轻人→男老板极可能没钱(有就写)；都是年轻人=公司刚成立无老人/爱优化35+ ③不定时聚餐下午茶旅游蹦迪泡脚→不定时=不一定；老板缺朋友主打陪伴属性 ④上班时间灵活→下班灵活=没下班=随地大小班 | 逐条"阅读理解"潜台词，制造爽点 |
| 4 职责反推 | ①负责小红书账号事宜(没写选题/拍摄)→极可能全包 ②抖音小红书快手Facebook→图穷匕见=全平台(他自己没做过要你试) ③选品不用管、珠宝文玩优先→没主推品=没卖出去；个人爱好想试 | 揭示"全平台全包+试错"真相 |
| 5 福利反推 | ①周一同休→单休；弹性=早上不上=晚上不下 ②全面接触项目=全包可能出镜 ③肯努力月薪过万=饼，到手可能<6K，绩效大底薪3K ④最好有直播经验=从零搭建+出镜+直播，实际底薪3K | 拆穿"饼"与低底薪 |
| 6 结尾CTA | "那么这份工作你要投吗？" | 反问立场+引导评论区互动 |

## 四、爆点 / 传播逻辑
- **爽点**：替打工人把"画饼"翻成"人话"，反PUA情绪价值强。
- **信息差**：给出可迁移方法论（薪酬范围公式、不定时=不一定、灵活=没下班），观众能直接用。
- **情绪共鸣**：吐槽老板、避坑、替弱势群体发声。
- **记忆点梗**："燕国地图""随地大小班""图穷匕见""优化"。

## 五、可复用套路（核心资产，建议进模块⑤脚本模板库）
1. **三段式拆解框架**：亮点 / 职责 / 福利，每条都做"官方话→潜台词"反转。
2. **JD潜台词方法论词典**（可直接作为脚本模板的"反推话术库"）：
   - 高薪 / 薪资区间 → 取最小值；无区间=就是那个数
   - 不定时XX → 不一定有
   - 时间灵活 → 下班灵活=没有下班
   - 都是年轻人 → 公司新/无老人，或爱优化大龄
   - 老板帅气/好说话 → 男老板可能没钱（有就写出来）
   - 全面接触项目 → 啥都你干
   - 肯努力月薪过万 → 饼，底薪低绩效高
3. **钩子公式**：用 JD 原话的离谱反差开场（"早上可以不上班/晚上可以不下班"）。
4. **结尾公式**：以"这份工作你要投吗？"反问，制造立场与互动。
