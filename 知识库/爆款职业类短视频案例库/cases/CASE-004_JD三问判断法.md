# 一个JD能不能投，你只问自己3个问题（一通百通）

## 一、案例概要
- 来源：用户提供的小红书视频口播稿。
- 一句话：不拆单条 JD，而是教一套**可迁移的通用判断方法**（3 个问题 + 结果三分），再用 A/B 两份新媒体运营 JD 做正反实操，是"授人以渔"型内容。

## 二、选题与定位
- 目标岗位：通用（以新媒体运营 A/B 岗为例）
- 行业 / 城市：通用求职方法论 / 未提供
- 选题角度：JD 判断方法论、反海投焦虑
- 受众：求职者（尤其应届/转行/gap，容易陷入"看岗—改简历—海投"陷阱的人）
- 钩子原文："我是来终结这个话题的，一个JD能不能投，你只用问自己3个问题，学会了这个方法是一通百通"

## 三、内容结构拆解
| 段落 | 原文梗/要点 | 功能 |
|------|------------|------|
| 1 开场权威钩子 | "我是来终结这个话题的" | 建立方法论权威人设 |
| 2 抛方法论·Q1 | 这工作到底要你干嘛？能否用自己的话说出每天干啥；说不出具体=坑 | 核心判断维度① |
| 3 方法论·Q2 | 能让你成长还是当耗材？坑在"把压力包装成机会" | 核心判断维度② |
| 4 方法论·Q3 | 值不值得花时间投？好岗长经验/作品/漂亮简历；烂岗长黑眼圈 | 核心判断维度③ |
| 5 结果三分法 | 投 / 改简历投 / 不投 | 把方法落成可执行结论 |
| 6 案例实操·A | A岗所有工作基于内容 → 能投（正常岗） | 正向样例 |
| 7 案例实操·B | B岗什么都有往一个岗堆 → 无深度；写"应届可投"但要成熟要求=低价买成熟活 | 反向样例+识别法 |
| 8 升华·反常识 | 把精力前置放在"筛选JD"而非海投；简历+JD丢给AI问这3问 | 方法落地+引流AI |
| 9 结尾 | 价值升华："人差距在看机会的能力"，耐着性子找 | 情绪收束+行动建议 |

## 四、爆点 / 传播逻辑
- 实用价值：给了一套**一通百通**的可迁移框架，收藏率高。
- 信息差/反常识："把精力前置放筛选JD，而非包装低胜算投递"戳中海投误区。
- 情绪价值：精准安抚求职焦虑，给出掌控感。
- 人设：过来人/终结者，权威感强。

## 五、可复用套路（核心资产 → 喂模块⑥）
1. **"JD三问判断法"**：①这工作到底要你干嘛（能否说清每天）②能成长还是当耗材（压力≠机会）③值不值得花时间投（长经验还是长黑眼圈）。
2. **结果三分**：投 / 改简历投 / 不投。
3. **"压力包装成机会"识别**：把高强度/打杂包装成"锻炼""机会"是坑的信号。
4. **"低价买成熟活"识别**：写"应届可投/经验不限"却要成熟岗全部要求 → 想用低价雇成熟工。
5. **"前置筛选"理念**：求职精力应放在筛 JD（A 步），而非无效海投。
6. **结构可复制**：权威钩子 → 抛方法 → 正反案例实操 → 升华行动，是"方法论教学型"通用骨架。

## 六、文案与表达特征
- 口语但有条理，善用"坑就在这里""我这句话写下来"强调重点。
- 用 A/B 对比降低理解成本。
- 结尾从方法升到人生观（"看机会的能力"），拔高价值。

## 七、风险 / 合规点
- 方法论类，合规风险低；但"一通百通""再也不用看任何攻略"略绝对，标注为**经验性方法**，非绝对真理。
- "把简历和JD丢给AI"涉及引导使用 AI，须提示用户注意隐私（勿传含个人身份/机密信息的简历）。
