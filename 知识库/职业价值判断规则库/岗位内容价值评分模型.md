# MODEL-001 V2 · JD选题价值评分模型

> **定位**：本模型是《这份工作能去吗？》内容生产的**选题守门人（Gatekeeper）**。
> **它判断的是**：「这份 JD 是否值得做成一期职业认知短视频」。
> **它不判断的是**：① 这个岗位是不是好岗位；② 建议用户是否选择这个职业。
> 账号是**知识型职业内容**（拆解真实 JD、帮大学生理解岗位真实情况），不是招聘广告、不是岗位推荐、不是职业营销。

---

## 一、评分维度（6 维，每维 1–5 分，权重和 100%）

| # | 维度 | 权重 | 1分（低） | 3分（中） | 5分（高） |
|---|------|------|----------|----------|----------|
| D1 | 点击动机 | 35% | 三项都弱 | 一项中等 | 至少两项强 |
| D2 | 应届生相关性 | 10% | 仅3-5年+ | 1-3年可投 | 大量实习/校招对口 |
| D3 | JD认知差 | 25% | 信息透明 | 有常见误区 | 需翻译/强误解/隐藏多 |
| D4 | 讨论张力 | 15% | 无讨论点 | 一般讨论 | 观点分歧/反差强 |
| D5 | JD可拆解性 | 10% | 仅"协助/安排"信息过少 | 部分可拆 | 场景+工具+流程+能力全 |
| D6 | 实用信息增量 | 5% | 纯情绪无收获 | 部分可学 | 给判断方法/技能方向 |

### D1 点击动机（35%）— 子指标
判断用户**为什么愿意点击**。由三个子指标综合得出 D1 的 1–5 分：
- **A 财富吸引**：高薪可能性 / 收入想象空间。
  - 5：高薪噱头强（如出海高薪、月薪过万、收入想象大）
  - 3：市场中位薪资
  - 1：偏低平淡、无想象空间
- **B 身份相关**：是否适合大量学生、与毕业就业强相关、易引发"这是不是适合我"。
  - 5：大量学生可投 / 强毕业相关 / 易引发自我映射
  - 3：部分相关
  - 1：仅资深职场
- **C 好奇冲突**：认知差 / 反差 / 值得解释的问题。
  - 5：强反差或经典误解（如"海外运营=英语好就行？""产品经理每天画原型？"）
  - 3：有一般误区
  - 1：信息透明无冲突

> **D1 打分法**：三项中两项达 5 → D1=5；一项达 5 或两项达 3 → D1=4；一项达 3 → D1=3；均弱 → D1≤2。回溯须说明命中了哪个子指标。

## 二、综合评分与价值等级

- **综合评分** = ( D1×0.35 + D2×0.10 + D3×0.25 + D4×0.15 + D5×0.10 + D6×0.05 ) × 20 → **0–100 分**
- **内容价值等级**：
  - **S**（强烈推荐制作）：≥ 80
  - **A**（推荐制作）：65–79
  - **B**（不优先）：50–64
  - **C**（暂缓/不优先）：< 50
- **制作策略**：**S / A → 制作**；**B / C → 不优先制作**（对应类型4 普通职业介绍）。

## 三、标签体系（替代复杂嵌套 RULE）

> 方向判定只用**标签组合**，不写互相嵌套的 IF-THEN 规则链。模型从 JD + 模块②③④ 提取以下标签：

| 标签 | 触发条件（机判依据） |
|------|---------------------|
| 高薪吸引 | D1-A≥4（薪资噱头/收入想象） |
| 学生相关 | D2≥4 或 JD 写"实习/校招/应届" |
| 认知差 | D3≥4（JD需翻译/大众误解/隐藏多） |
| JD复杂可拆 | D5≥4（场景/工具/流程/能力明确） |
| 讨论反差 | D4≥4（观点分歧/真实体验反差） |
| 风险提醒 | 命中风险标签库（见下，如"招运营实为招主播""薪资画饼""押金培训贷""地址异常"） |

**风险标签库**（原 RULE-001 已整合进本体系，作为标签备查）：
`招运营实为招主播` / `薪资画饼(无责底薪+绩效模糊)` / `押金·培训贷` / `地址异常(居民楼/偏僻园区)` / `无明确业务只讲前景` / `强制加班写"抗压")`。
> 风险标签仅用于"提示用户注意"，**不构成绝对批判**（见第五节生产原则）。

---

## 四、内容方向判定（4 类型，标签驱动）

按优先级匹配（命中即定，不叠加复杂规则）：

| 顺序 | 条件 | 内容方向 | 内容内核 |
|------|------|----------|----------|
| 1 | 风险标签命中 | **类型3 就业避坑提醒** | 点出隐藏信息/风险，避免绝对批判、不点名 |
| 2 | D1≥4 且 D3≥4 | **类型1 高价值岗位拆解** | "这个岗位到底值不值得了解？" |
| 3 | D5≥4 且 D3≥4 | **类型2 JD翻译课堂** | "招聘写的这些话，实际是什么意思？" |
| 4 | D3≥4 或 D4≥4 | **类型3 就业避坑提醒** | 信息差/反差型提醒 |
| 5 | 其余（D1/D3 均低） | **类型4 普通职业介绍** | 价值较低，不优先制作 |

> 实习岗默认偏"发展探索"视角（在类型1/2 框架下，切入"这段经历帮你探什么方向"）；风险提醒对实习岗同样适用但语气更轻。

## 五、职业内容生产原则（账号价值观，硬约束）

**避免**：
- 把岗位简单分为"好/坏"两极；
- 制造就业恐慌、贩卖焦虑；
- 无依据推荐（如"应届生都该去"）；
- 过度营销（软广、内推未披露复刻）。

**鼓励**：
- 提供**判断方法**（让用户自己能评估）；
- 解释岗位**真实含义**（JD 翻译、隐藏信息）；
- 帮助用户**形成职业认知**，而非替他做决定。

> 所有输出须内嵌：数据标出来源、不确定信息标"个人观点/待核实"、不替用户下"去/不去"的最终结论。

## 七、示例推演（验证可执行）

**例1 · 跨境电商运营（JD-011，避坑/风险）**
D1=4(A高薪3+B学生5+C冲突4→综合4) D2=3 D3=5 D4=5 D5=4 D6=4
综合=(4×.35+3×.10+5×.25+5×.15+4×.10+4×.05)×20=**83→S**
标签：认知差+讨论反差+风险(招运营实为招主播) → **类型3 就业避坑提醒**。
标题示例：①"跨境电商运营，真能出海赚美金还是变相主播？" ②"JD写'海外运营'，实际可能在干啥？" ③"投跨境岗前，这3个坑先看清"。
风险提示：风险标签来自模块④ CASE-002；薪资按 JD 区间，未夸大。

**例2 · 拓竹 IMC 整合营销实习（海外方向，实习岗）**
D1=5(A高薪3+B学生5+C冲突5→综合5) D2=5 D3=4 D4=3 D5=5 D6=5
综合=(5×.35+5×.10+4×.25+3×.15+5×.10+5×.05)×20=**89→S**
标签：学生相关+认知差+JD复杂可拆+实用增量 → D1≥4且D3≥4 → **类型1 高价值岗位拆解**（实习视角=发展探索）。
标题示例：①"拓竹实习一天250，这段经历能帮你探什么方向？" ②"IMC整合营销实习，JD里写的活到底接触啥？" ③"想冲出海市场，这份实习值不值得？"。
风险提示：拓竹为 JD 明示雇主（必要引用非营销）；实习岗不替用户下"去不去"结论。

## 八、模型维护（v1.x → v2 变更说明）
- **删除** v1.x 的 R1–R10 嵌套规则链，改为「六维评分 + 标签体系 + 四类型方向」。
- **维度重排**：原 D5成长/D6薪资（岗位质量维度）拆并——钩子半边进 D1 点击动机，坑半边回 D3/D4；新增 **D5 JD可拆解性**（内容素材）、**D4 讨论张力**替代"争议性"（避免制造焦虑）。
- **目标校正**：从"岗位质量评价"彻底转为"内容生产价值评价"；输出"内容方向"而非"推荐/不推荐岗位"。
- **防骗**：原 RULE-001 外置规则整合为「风险标签库」（第三节），仅作提示，不构成绝对批判。
- 模块② EXP / ③ IND 用于强化 D3 认知差、D4 反差、风险标签的判定精度。
