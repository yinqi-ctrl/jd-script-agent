# 职业价值判断规则库 · 建设规范与模板

> 模块定位：《这份工作能去吗？》职业探索类短视频内容策划智能体的**第⑥个核心知识库**，也是内容生产的**守门人（Gatekeeper）**。
> 作用：在调用模块⑤（脚本模板）之前，先判断"这个岗位值不值得做一期"，输出可执行的「内容价值评分 + 推荐指数 + 建议切入角度」，避免智能体对无话题岗位盲目产出。
> 上游：模块①（JD库）、模块④（案例库套路）；下游：模块⑤（脚本模板库 ST-002）。
> 本库核心是 `岗位内容价值评分模型.md`——一个**可计算、可触发、可执行**的规则集，而非理论分析。

---

## 一、本库需要包含的信息字段
1. **评分模型**：7 个维度的定义、1-5 评分锚点、判定信号、数据来源。
2. **权重表**：7 维权重（合计 100%），用于算综合分。
3. **判断规则**：IF-THEN 可执行规则（正向触发 / 负向暂缓 / 硬规则覆盖）。
4. **输出模板**：智能体对单个岗位的标准输出格式。
5. **示例推演**：至少 2 个（强烈推荐 / 暂缓）证明规则可跑。
6. **检索辅助**：`rule_id`、`tags`、`summary`、`related_kb`。

---

## 二、推荐数据来源（给某岗位打分时去哪取数）
- **模块① JD库**：取 `experience_requirement / salary_range / career_path / tags / content_angles`。
- **模块④ 案例库**：取同行业 `template_type`、套路词典命中数、`heat_level`。
- **模块⑤ ST-002**：判断能否套"JD阅读理解三段式"→ 影响传播潜力分。
- **（可选）联网核查**：岗位热搜、舆情、诈骗预警（如红鼎国际类公开报道）。
- **模块②/③（待建）**：真实体验反差、行业趋势，建成后回填增强"认知差/发展空间"判定。

---

## 三、数据整理规范
1. **单规则一文件 / 单模型一文件**：核心模型存 `岗位内容价值评分模型.md`；后续新增细分规则（如"防骗专项规则"）可另起 `规则_xxx.md` 并在本库 `_INDEX.md` 登记。
2. **评分可复现**：每个维度必须给"1-5 锚点 + 判定信号"，禁止凭感觉打分；打分时须能回溯依据。
3. **风险标签优先**：命中「风险标签库(RULE-001)」信号的，内容方向走类型3 就业避坑提醒并带【风险提醒】，不受等级阈值影响（V2 已取消 R1–R10 嵌套规则，改为六维评分+标签+四类型方向）。
4. **与上下游关联**：评分结论若触发制作，须在输出中指明"建议切入角度（对应 ST-002 变体）"与可关联 `case_id / jd_id`。
5. **合规护栏**：凡涉及地域/公司性质/诈骗预警的判断，输出必须带匿名化与"基于公开报道"声明，沿用模块④规范。

