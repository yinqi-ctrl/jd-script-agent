## 二、模型速览（MODEL-001 V2）
> 目标：判断「这份 JD 是否值得做成职业认知短视频」，**不是**评岗位好坏、**不是**替用户择业。
- **6 维度（1-5 分）**：D1 点击动机35% / D2 应届相关性10% / **D3 JD认知差25%（核心）** / D4 讨论张力15% / D5 JD可拆解性10% / D6 实用信息增量5%
- **综合评分** = Σ(分×权重)×20 （0-100）
- **内容价值等级**：S≥80 制作（优先）｜A 65–79 制作｜B 50–64 不优先制作｜C<50 不制作
- **标签体系**：高薪吸引 / 学生相关 / 认知差 / JD可拆 / 讨论反差 / 风险提醒(命中 RULE-001)
- **内容方向（四类型，非"推荐岗位"）**：
  - 类型1 高价值岗位拆解（D1≥4 且 D3≥4）→ ST-003
  - 类型2 JD翻译课堂（D5≥4 且 D3≥4）→ ST-002/ST-003 翻译骨架
  - 类型3 就业避坑提醒（风险标签 或 D3/D4 高，避免绝对批判）→ ST-002
  - 类型4 普通职业介绍（低价值，不优先）
- **输出模板**：岗位 / 岗位类型 / 综合评分 / 内容价值等级 / 主要价值 / 推荐内容方向 / 视频切入角度(3标题) / 风险提示

## 三、方向 → 模板链路

- （模块④ 案例：类型3 CASE-001/002/003/005/006；类型1 CASE-007/008/009；类型4 方法论 CASE-004）

## 四、使用方式
1. 输入一条岗位（通常带 JD）→ 按 6 维度逐项打分（回溯依据）。
2. 算综合分 → 得内容价值等级（S/A 制作，B/C 不优先）。
3. 打标签 + 判内容方向（四类型）→ 选 ST-002 / ST-003。
4. 输出标准模板；若 S/A → 交模块⑤ 生产，并回填 related_kb。
