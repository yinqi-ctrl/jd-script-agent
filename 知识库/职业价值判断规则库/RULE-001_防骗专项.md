# RULE-001 风险标签库（原防骗专项）

> 本规则已整合进 **MODEL-001 V2 第三节「风险标签库」**：信号命中即打「风险提醒」标签，内容方向走**类型3 就业避坑提醒**。V2 不再使用 R1–R10 嵌套规则，故原 R7 已废止；本文件保留信号清单作标签备查与持续迭代。

## 一、识别信号（可机判，命中任一即触发）
1. **挂羊头卖狗肉**：JD 标题写「运营/助理/顾问」，正文要求出镜直播、才艺展示、自带粉丝量、每日开播 → 实为招主播/引流。
2. **先交钱**：要求押金、培训费、服装费、资料费、垫付货款/刷单本金 → 资金盘/刷单。
3. **地址异常**：办公地为居民楼/虚拟注册地/集中投诉片区；或拒绝告知实地办公点。
4. **薪资话术**：「无责底薪+高提成」「轻松过万」但无明确 base 与计算口径；或 base 极低靠"画饼"。
5. **跨境岗通病**：以「出海运营/海外助理」为名，实为刷单、私域引流、杀猪盘导流、协助走账。
6. **私密沟通**：要求脱离招聘平台、转私人微信/境外软件沟通，或要求提供银行卡/证件。

## 二、触发后的动作（命中风险标签 → MODEL-001 V2 类型3）
- 命中风险标签 → 内容方向=类型3 就业避坑提醒；建议制作（不单纯因分数低而丢弃），并带【风险提醒】。
- 视频内带【风险提醒】横幅/口播（不点名具体公司，除非 JD 明示雇主且属必要引用）；口吻为提示而非绝对批判。
- 结尾加提示：「以官方渠道核实岗位，勿轻信私聊邀约」。
- 合规护栏：不编具体受害者故事、不点名未证实公司、潜台词标"个人观点"。

## 三、关联案例
- **CASE-002**（跨境运营"招运营实为招主播"骗局）→ 典型命中信号 1 + 5。
- 其余骗局形态随模块④新增案例持续回填本规则。

## 四、维护
- 新骗局形态出现 → 在第一节追加信号（编号延续），不回改 MODEL-001。
- 每季回溯命中率，误杀/漏杀均记录校准。
