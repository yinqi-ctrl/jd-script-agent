# 行业趋势与职业发展数据库 · 总索引

> 模块③：辅助智能体判断「岗位未来发展情况」。与①JD（现状）、②真实体验（体感）互补，形成「现状—体感—趋势」三层信息。

## 一、定位与统计
- 定位：岗位行业趋势 / 职业发展前景判断库。
- 统计：**17 条 in_scope 条目**，覆盖 5 大类的全部 in_scope 角色（合并最近岗位，别名覆盖子角色）。
- `out_of_scope` 角色（医生/律师/公务员/程序员/算法/医师/教师/券商等）本库**不建条目**，不参与生成。
- 数据性质：均为 **2026-08-15 联网综合**（聚合行业报告/媒体/招聘平台/知乎脉脉讨论），`data_quality: A`；趋势表述避免绝对预测。

## 二、智能体检索与联网回填机制（关键）

智能体拿到一条 JD 后的标准动作：

1. **先检索本库**：用 JD 的 `profession` / `scope_role` / `tags` 匹配本库 `profession` / `aliases` / `scope_role`。
   - 命中 → 引用对应 IND 条目的「行业背景/发展路径/市场需求/风险/短视频表达价值」。
2. **信息不足则联网**：若命中 in_scope 但本库**无对应 IND**（或条目 `data_quality: C` 待补）→ **触发联网检索**，按本库 6 段结构回填新 IND（或补全 C 条目），frontmatter 标 `collect_date` 与 `data_source`。
3. **out_of_scope 不处理**：直接跳过本库，不生成趋势内容。
4. **合规**：所有趋势用「目前看/大概率/存在 X 风险」表述，禁止绝对预测；标注「趋势基于公开信息综合，非投资建议」。

> 部署提示（迁 Coze 等）：本库进**知识库(RAG)**，prompt 中写明上述"先检索→不足联网"流程与合规护栏；规则类（评分/脚本模板）不当 RAG。

## 四、与上下游模块的衔接
- **模块① JD库**：提供岗位现状（职责/薪资/门槛）→ 本库补充"未来"。
- **模块② 真实体验库**：提供从业者体感（认知差）→ 本库补充"行业大势"。
- **模块⑥ 价值判断规则库**：本库「风险分析/短视频表达价值」可直接喂 MODEL-001 V2 风险标签（类型3）与高价值信号（类型1）判定。
