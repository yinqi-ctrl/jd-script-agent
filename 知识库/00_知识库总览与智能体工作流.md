## 二、六大模块详解

### ① 岗位JD数据库（现状层）
- **作用**：提供岗位"现在是什么样"——职责、硬/软技能、薪资结构、亮点、痛点、适合/不适合人群、职业路径。
- **核心设计**：E 组"内容策划增强字段"（selling_points / pain_points / content_angles）直接喂下游选题，区别于普通 JD 爬虫。
- **数据**：全部 `quality: A`（联网核查+综合建模，非实时在招帖），含 `source`/`data_note` 可追溯。

### ② 职业真实体验数据库（体感层）
- **作用**：提供"从业者真实体感"，制造官方 JD vs 真实体验的认知差。
- **结构**：基本信息 → 真实工作状态 → 从业者反馈 → 认知差 → 视频创作价值（双方向）。
- **数据**：全部 `data_quality: A`（联网综合，聚合知乎/脉脉/小红书/行业报道，**非单人访谈**），标"仅供参考"。

### ③ 行业趋势与职业发展数据库（趋势层）★本次新建
- **作用**：判断"岗位未来怎么走"——行业背景、发展路径、市场需求、风险（含被 AI 替代）、短视频表达价值。
- **结构（用户指定 6 段）**：行业背景 / 职业发展路径 / 市场需求 / 风险分析 / 短视频表达价值。
- **数据**：全部 `data_quality: trend_summary`（2026-08-15 联网综合），表述避免绝对预测（"目前看/大概率/存在风险"）。
- **关键机制**：固化"JD 先检索本库 → 不足则联网回填"运行时行为（详见第四节）。

### ④ 爆款职业类短视频案例库（套路层）
- **作用**：提炼已验证的爆款结构，作为智能体写脚本的"武器库"。
- **类型**：类型3 就业避坑提醒 4（CASE-001/002/003/006）、类型1 高价值岗位拆解 3（CASE-007/008/009）、类型4 方法论教学 1（CASE-004）。
- **可复用套路**：JD阅读理解三段式、潜台词词典、薪酬范围公式、防骗识别维度、一人多岗汇总法、JD三问判断法、高价值拆解框架。
- **数据表现**：点赞/收藏等用户未提供，一律标"待补"，**不编造**。

### ⑤ 短视频脚本模板库（生成层）
- **作用**：把①②③④组装成口播稿的骨架。
- **三个模板**：ST-001 通用黄金结构（底座）、ST-002 避坑型（JD原话钩子→三段式反推→避坑总结+反问CTA）、ST-003 高价值型（被低估钩子→岗位画像→正向拆解→为什么高价值→适合谁→CTA）。

### ⑥ 职业价值判断规则库（决策层）
- **作用**：选题守门人，判断是否"值得做一期"及"做哪个方向"。
- **模型**：MODEL-001 V2，6 维度（**D1 点击动机35%** / D2 应届相关10% / **D3 JD认知差25%（核心）** / D4 讨论张力15% / D5 JD可拆解性10% / D6 实用增量5%），综合分 0–100 → 内容价值等级 S/A（制作）· B/C（不优先）。
- **方向（非"推荐岗位"）**：类型1 高价值岗位拆解 / 类型2 JD翻译课堂 / 类型3 就业避坑提醒 / 类型4 普通职业介绍；以"六维评分+标签体系"判定，已删 R1–R10 嵌套规则。

### ★ 覆盖范围权威口径（00_覆盖范围与岗位分类.md）
- **仅分析 5 大类 in_scope 岗**：内容运营 / 产品商业 / 出海跨境 / 增长数据 / 企业通用。
- **不覆盖**：医生/律师/公务员/强资质/长培养职业（程序员/算法/医师/教师/券商等），一律 `out_of_scope`，不建库、不参与生成。

## 三、智能体工作流（端到端）

**输入**：一条 JD 文本 或 指定岗位名（如"数据运营"）。

```
[0] 范围判定 + 方向初判 ── 00_覆盖范围与岗位分类.md + MODEL-001 V2（实习岗发展探索）
  │  0.1 范围：out_of_scope → 礼貌拒答/说明不覆盖
  │  0.2 岗位类型：实习岗 / 正职岗
  │  0.3 方向初判：类型1 高价值 / 类型2 翻译 / 类型3 避坑 / 类型4 普通（结合 ⑥ V2 评分）
  │  ▼ 研判方向分野（关键）：
  │     实习岗 → 重心=发展探索（试出哪个正式方向+含金量+后续怎么走），坑点轻带，不做纯避坑
  │     正职岗 → 重心=岗位分析(避坑 or 高价值) + 前景
   ▼  in_scope ↓
[1] 检索① JD库 ── 匹配 profession/scope_role/tags
   │  命中 → 取"现状"(职责/薪资/门槛/亮点痛点)
   │  未命中(in_scope) → 联网检索，按①模板建 JD 并回填
   ▼
[2] 检索② 真实体验库 ── 匹配 profession/tags
   │  命中 → 取"认知差"(官方vs真实体感)
   │  未命中(in_scope) → 联网检索，按②模板回填 EXP
   ▼
[3] 检索③ 行业趋势库 ── 匹配 profession/scope_role
   │  命中 → 取"趋势/风险/短视频表达价值"
   │  未命中(in_scope) → 联网检索，按 6 段模板回填 IND
   ▼
[4] ⑥ 价值判断 ── MODEL-001 V2
   │  6维打分 → 内容价值等级(S/A 制作 · B/C 不优先)
   │  打标签 + 判内容方向（类型1/2/3/4）
   │  命中风险标签 → 类型3 并带【风险提醒】
   ▼
[5] ④ 案例套路 ── 按内容方向取武器库
   │  类型3 避坑 → JD阅读理解三段式 + 潜台词词典 + 风险维度
   │  类型1 高价值 → 高价值拆解框架
   │  双线 → 两者组合
   ▼
[6] ⑤ 脚本生成 ── ST-002(避坑) / ST-003(高价值) + ST-001底座
   │  填入①②③信息 + ④套路 → 产出口播稿
   ▼
[7] 合规护栏 ── 统一校验
   │  软广/内推(CASE-005/007性质)禁无披露复刻
   │  潜台词标"个人观点"；不编数据；地域判断须基于公开报道
   ▼
[8] 输出给用户（建议用③"短视频表达价值"段做标题钩子）
```

**三层信息互补**：①现状（是什么）→ ②体感（真实吗）→ ③趋势（将来呢），共同喂给 ⑥判断 → ④套路 → ⑤成稿。

**联网回填约定**（贯穿 ①②③）：命中 in_scope 但本库无条目 → 触发联网检索，按对应模板结构回填新条目，frontmatter 标 `collect_date`/`data_source`；`out_of_scope` 不建不生成。

## 四、数据准确性与合规护栏

- **数据真实**：JD 均标 `quality: A`（联网核查+综合建模，非实时在招帖）；案例数据表现未提供则标"待补"，绝不编造。
- **趋势克制**：模块③用"目前看/大概率/存在 X 风险"表述，禁绝对预测，标"趋势基于公开信息综合，非投资建议"。
- **合规红线**：
  - 案例/生成内容不得无披露复刻软广（CASE-005）、内推（CASE-007）；
  - 潜台词须标"个人观点"；
  - 不点名具体公司/老板（匿名化）；
  - 绝对化地域判断禁止（须基于公开报道）；
  - 防骗内容标【防骗警示】。
