# 短视频脚本模板库 · 总索引

> 建设规范见 `00_建设规范与模板.md`。本库承接模块① JD + 模块④ 案例套路，产出可拍摄脚本。

## 一、模板总表

| template_id | 名称 | 方向 | 基于案例 | 关联 |
|-------------|------|------|---------|------|
| ST-001 | 通用_黄金结构 | 通用底座 | 用户提供的通用短视频框架 | 所有模板底座 |

## 二、内容方向 → 模板映射（MODEL-001 V2 四类型）
- 模块⑥ MODEL-001 V2 先判「内容方向」：
  - **类型1 高价值岗位拆解**（D1≥4 且 D3≥4）→ 套 **ST-003**
  - **类型2 JD翻译课堂**（D5≥4 且 D3≥4）→ 套 ST-002/ST-003 取"翻译"骨架
  - **类型3 就业避坑提醒**（风险标签 或 D3/D4 高）→ 套 **ST-002**
  - **类型4 普通职业介绍**（低价值）→ 不优先制作
- **落地产出统一格式**：所有脚本按 `脚本表格输出规范.md` 输出 5 列竖版分镜表（时长/画面镜头竖版/口播台词/屏幕字幕/节奏·语气）。

## 三、ST-001 通用黄金结构（底座要点）
- 开头(0-3s)强留人：痛点提问/反差悬念/直接给利益。
- 正文(3-50s)强价值：核心观点+分层举证，每10s一个有效信息。
- 结尾(50-60s)强闭环：干货总结 + 指令引导（评论/点赞/收藏/行动）。
- 四要素：人设统一 / 单主题 / 价值（实用·情绪·娱乐·福利）/ 节奏紧凑。
- 四避坑：不铺垫过长 / 不书面生硬 / 不无闭环 / 不虚假同质化。

## 四、使用方式
1. 模块⑥ MODEL-001 V2 判内容方向（类型1/2/3/4）+ 等级（S/A 制作，B/C 不优先）。
2. S/A → 按方向选 ST-002 或 ST-003。
3. 填入模块① JD 要点 + 模块④ 同类案例套路 → 按《脚本表格输出规范》产出 5 列分镜脚本。
4. 输出前过一遍对应模板的合规边界 + 规范合规护栏。
