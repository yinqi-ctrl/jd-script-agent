# 通用短视频黄金结构（底座模板）

> 本模板是**所有垂直脚本的底座**。JD拆解型（ST-002）即在其上派生。智能体生成任何脚本前，先满足本底座，再叠加垂直结构。

## 一、定位与适用
适用于绝大多数知识/测评/避坑类短视频。所有垂直模板都必须符合下面的"黄金结构 + 四要素 + 避坑"。

## 二、短视频脚本黄金结构

### 1. 开头（0-3秒，强留人）
无铺垫、不寒暄，仅用三种有效句式：
- **痛点提问**：「为什么你努力护肤却没效果？」
- **反差悬念**：「别再乱买零食了，90%的人都踩坑」
- **直接给利益**：「3个居家小技巧，帮你省下上千开销」

### 2. 正文（3-50秒，强价值）
聚焦一个主题，采用「核心观点 + 分层举证」结构，以步骤、案例、对比、细节补充佐证。**每10秒输出1个有效信息**，全程无废话、无流水账。

### 3. 结尾（50-60秒，强闭环）
固定两种收尾方式：
- **干货总结**强化记忆；
- **指令引导**提升数据：含评论互动、点赞收藏、行动、产品转化四类指令。

## 三、短视频脚本四大必备要素
| 要素 | 要求 |
|------|------|
| 人设要素 | 统一口吻、风格、表达方式，打造记忆点，保障账号风格统一 |
| 主题要素 | 单条脚本单一主题，诉求明确，无多内容堆砌 |
| 价值要素 | 具备实用/情绪/娱乐/福利价值之一，产生停留与互动动机 |
| 节奏要素 | 台词精简、字幕精准、画面适配，无无效镜头与冗余台词 |

## 四、高频避坑指南
- **避开头铺垫过长**：拒绝开场自我介绍/背景铺垫，3秒切入核心。
- **避台词书面生硬**：全程口语化、接地气，避免晦涩说教。
- **避结尾无闭环**：必须搭配总结或互动指令。
- **避内容同质化、虚假化**：拒绝搬运抄袭、夸大虚假，保障原创真实可落地。

## 五、通用万能脚本模板（套用骨架）
| 时段 | 模块 | 动作 |
|------|------|------|
| 0-3s | 开篇抓流 | 痛点提问/反差悬念/直白利益。示例：「90%的人都做错了！XX正确做法其实很简单」 |
| 3-50s | 正文 | 点明核心问题 → 分步拆解实操 → 案例/对比佐证，层层递进 |
| 50-60s | 结尾收口 | 汇总知识点 + 互动提问/行动指令，引导点赞收藏评论行动 |

## 六、与垂直模板的关系
- JD拆解型（ST-002）把"正文"替换为**三段式 JD 反推**，把"开头"固定为**JD原话反差/提问**，把"结尾"固定为**反问CTA**。
- 任何新垂直模板（vlog型、薪资揭秘型…）都应在本底座上做"正文模块替换 + 钩子/结尾定制"。
