# 脚本表格输出规范（竖版分镜）

> 模块⑤ 统一输出格式。所有脚本（ST-002 避坑 / ST-003 高价值 / 双线）最终**交付物均为本 5 列竖版分镜表**，便于直接进拍摄/剪辑。
> 适用平台：小红书 / 抖音（手机竖屏 9:16）。

---

## 〇、时长分级与联网复核（前置硬要求，引用《00_写作操作手册_整合版》）

- **时长分级**：基础版 35–55s（单判断+清单）/ 标准版 55–75s（双线或实习探索）/ **深度版 80–120s（联网复核到丰富素材时使用，每 8s 一个信息点 + 1–2 反转）** / 长拆解版 2–3min。
- **联网复核**：脚本中每个事实性断言（公司数据/行业趋势/舆论事件/薪资基准/前景）须先联网检索并在脚本末尾附 **「信息核验表」**（事实 / 来源 / 检索日期 / 结论 / 置信度）；未核验信息须标「公开信息/个人观点」或不写。

## 一、表格结构（5 列，不可省略）

| 时长 | 画面镜头（竖版） | 口播台词 | 屏幕字幕 | 节奏·语气 |
|------|----------------|----------|----------|-----------|

**列定义**
- **时长**：累计起止时间点，如 `0:00-0:03`；脚本末尾标注总时长（建议 60s / 90s / 2–3min）。
- **画面镜头（竖版）**：9:16 构图与景别 + 切换说明。常用景别：
  - `手机自拍中景`（半身，主播出镜）
  - `特写`（手势 / 表情 / 单物）
  - `JD截图字幕卡/贴图`（JD 原文放大成卡片，或画中画/贴角叠加）
  - `分屏对比`（左原话 / 右"人话"）
  - `录屏`（后台 / 数据界面）
  - `素材空镜`（公司大楼 / 工位，仅可用公开素材）
> **贴图优先原则**：JD 截图 / 文本 / 数据一律以**贴图形式**呈现（画中画、贴角、字幕卡、分屏），主播出镜说话即可，信息作为屏幕贴图叠加；**不要设计"手持截图对准镜头"之类的表演式动作**（不自然、不像真实拍摄）。
- **口播台词**：口语化、第二人称"你"、短句；潜台词/主观判断句末尾可加`（个人观点）`。
- **屏幕字幕**：提炼关键词或反转句，**≤14 字/条**，强对比；与口播不同句，做"视觉锤"。
- **节奏·语气**：标注快慢、情绪、切点（如 `快·吐槽` `慢·算账` `加重·警示` `上扬·互动`）。

## 三、合规护栏（写进每一条脚本的"备注"）
- 潜台词/主观判断须可辨为**个人观点**，不宣称事实；传闻（如"242"）不得引为事实。
- 不点名具体公司/老板，用"某/某公司"；地域判断须基于公开报道，禁止绝对化。
- 薪资用区间最小值公式推导，标注"推导非承诺"；无数据不编造。
- 含风险标签/类型3 就业避坑提醒的内容，须带【风险提醒】字幕（不用绝对批判口吻）。
- 商单/内推性质（CASE-005/007）不得无披露复刻。
- 去AI味：避免破折号（——）；避免「不是…而是…」「虽然…但是…」等套路句式；口播像真人聊天，短句、口语、有网感。

## 四、与 ST-002 / ST-003 的关系
- ST-002（避坑）与 ST-003（高价值）决定**内容与钩子方向**，本规范决定**最终呈现表格**。
- 双线视频：主表按 ST-002 排，高价值副线作为倒数第二段插入（见骨架 0:55-1:05）。
- 总时长超 60s 时，按段落等比扩展；每 10s 至少 1 个信息反转点。
- 所有脚本**须先过《00_写作操作手册_整合版》第 10 节自检清单**（算法友好 + 合规 + 联网复核）再交付。
