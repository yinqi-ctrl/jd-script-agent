# JD阅读理解/避坑拆解型 主模板（这份工作能去吗？）

> 频道招牌格式。把一条招聘 JD 的官方话术逐条翻成打工人视角的"潜台词"，帮观众避坑。
> 底座：通用黄金结构（ST-001）；套路来源：CASE-001、CASE-002。
> 对应 MODEL-001 V2 内容方向：**类型3 就业避坑提醒**（含风险标签亦走类型3）。

## 一、定位与适用
- 输入：一条岗位 JD（或 JD 要点：岗位/城市/薪资/亮点/职责/福利/任职要求/地址）。
- 输出：60s 内短视频脚本（分镜 + 口播），结构稳定、口吻统一、可量产。
- 适用：招聘 JD 类岗位（运营/跨境电商/互联网/销售等）；体制内、自由职业等无公开 JD 的岗位不适用本模板。

## 二、结构骨架（套用通用黄金结构）

| 时段 | 模块 | 动作 | 要点 |
|------|------|------|------|
| 0-3s | 开头·钩子 | 用 JD 原话制造反差/提问 | 三选一（见下）；不寒暄 |
| 3-50s | 正文·三段式反推 | 亮点→职责→福利，每段"官方话→潜台词" | 每10s一个反转信息点；注入薪酬公式与潜台词词典 |
| （可选）40-50s | 正文·公司/地址研判 | 防骗型才加 | 基于公开报道，不绝对化 |
| 50-60s | 结尾·闭环 | 避坑总结 + 反问 CTA | "这份工作你要投吗？"引导评论 |

**钩子三选一**：
- 提问式：「这工作能去吗？{{岗位}} {{薪资区间}}」
- 反差式：「{{JD原话反差句，如'早上可以不上班'}}……{{反转潜台词，如'晚上可以不下班'}}」
- 利益式：「一条 JD 教你避开{{城市}}{{岗位}}的最大坑」

## 三、四要素落实
- **人设**：毒舌避坑、信息差搬运工、"替打工人翻译老板话"的记忆点。
- **主题**：单岗位单条 JD 拆解，不堆多岗位。
- **价值**：实用（避坑方法论）+ 情绪（反画饼/反PUA共鸣）+ 娱乐（梗）。
- **节奏**：短句、反问密集、第二人称"你"、快切；无废话。

## 四、口吻与边界（合规·量产不飘）
- **固定口吻**：口语化、反问多（"什么意思啊""记住"）、敢用梗（"燕国地图""随地大小班""图穷匕见"）。
- **潜台词属主观解读**：正文须标注"个人观点，供参考"，不宣称事实。
- **匿名化**：不点名具体公司名与老板；用"某公司/某老板"。
- **地域/公司性质判断**：须基于公开报道，表述为"据报道集中地""需慎重"，**禁止绝对化与地域歧视**（如案例二"红鼎国际"仅作提示，不定义"必骗"）。
- **数据诚实**：薪资用区间取最小值公式推导，注明"推导非承诺"；无数据不编造。
- **禁用词**：不出现人身攻击、诽谤、地域黑、虚假宣称。

## 五、潜台词方法论词典（反转速查，喂给智能体）
| JD 原话常见表述 | 潜台词反转 |
|----------------|-----------|
| 高薪 / 薪资6K-11K | 区间取最小值；无区间=6K；"高薪"多为相对当地基准 |
| 薪资范围给区间但无结构 | 含底薪+提成+绩效，顶满才到上限，实际常打5折 |
| 老板帅气/好说话/都是年轻人 | 男老板可能没钱（有就写）；公司刚成立无老人 / 偏好优化35岁以上 |
| 不定时聚餐/下午茶/旅游 | "不定时"=不一定有 |
| 上班时间灵活 | =下班时间灵活=没有下班=随地大小班 |
| 每周X休息 / 弹性 | 多为单休；"弹性"常指早可不上=晚可不下 |
| 肯努力轻松月薪过万 | 画饼，到手可能低于底薪，绩效占比大、底薪常3K |
| 负责XX账号相关事宜（未写细分） | 极可能全包（选题+拍摄+剪辑+出镜） |
| 多平台（抖音/快手/FB…）经验均可 | 图穷匕见=全平台，对方没做过要你从零试 |
| 选品不用管，某类目优先 | 暂无主推品=没卖出去；个人爱好想试 |
| 性格开朗/有直播经验优先 | 要你出镜当主播，运营变两份工 |
| 大专及以上/有互联网思维 | 门槛虚词，降低门槛广撒网骗投 |
| 不要求英语/行业经验（跨境岗） | 重大预警：实际可能做无关工作（如海外主播） |
| 能适应加班 | =无偿加班，为绩效考核 |
| 地址在知名"雷区" | 公开报道集中地，需更慎重（提示非定性） |

## 七、示例片段（基于 CASE-002 改写示范）
- 开头：「这工作能去吗？跨境电商 10-15K——是行业真缺人，还是挂羊头卖狗肉？」
- 正文：「薪资给 10-15K，聪明同学已经注意到没写结构，那就是底薪+提成，顶满也就 10K，实际打对折拿 4-5K。职责写'平台不清楚'——你就是一块砖。任职要'直播经验优先'，运营变两份工，警惕以招运营骗签主播合同。地址观音桥红鼎国际，公开报道的雷区集中地，更要慎重。」
- 结尾：「这份挂羊头卖狗肉的工作，你还要去吗？」
