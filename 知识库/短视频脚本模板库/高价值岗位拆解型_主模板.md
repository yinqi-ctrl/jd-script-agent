# ST-003 高价值岗位拆解型 · 脚本主模板

> 与 ST-002（JD阅读理解/避坑拆解型）**平级**，是《这份工作能去吗？》系列的第二方向。
> 区别：ST-002 是"反推潜台词、吐槽揭秘"；ST-003 是"正面介绍+分析岗位/公司，讲清为什么高价值/稀缺"。
> 模板↔V2方向：ST-002 = 类型3 就业避坑提醒；ST-003 = 类型1 高价值岗位拆解。

---

## 一、定位与适用
- **什么时候用**：岗位本身有吸引力（高薪/稀缺/前景好/被低估），受众需要"看懂它、判断要不要冲"。
- **不适用**：坑岗、画饼岗、防骗预警 → 走 ST-002（对应类型3 就业避坑提醒）。
- **典型来源**：模块① JD + 模块③ 行业趋势（讲清"高价值"需数据/趋势支撑）。

## 四、方法论要点（讲清"高价值"的四招）
1. **角色类比降维**：用受众熟悉的角色（中型CMO）解释陌生岗位。
2. **JD回扣原文**：正向拆解时引用 JD 原句，增强可信（区别于 ST-002 的反推）。
3. **行业阶段解释薪酬**：从"行业所处阶段 + 数据基础设施"解释为什么稀缺高薪（认知差来源）。
4. **公司三重背书**：产品成熟度 / 盈利稳定性 / 团队氛围 → 为什么"现在"加入 ROI 高。
5. **赛道难点洞察**（加分）：阶级价值、信任门槛、本土化等，体现专业度。

## 六、合规边界（红线）
- **商单/内推识别**：若原始素材含具体公司 + 内推/招聘引导（如 CASE-007），属商单/内推性质；**生成内容不得复刻未披露的商业合作、内推链接或具体公司背书**。可学结构，不可搬运公司 specifics。
- **数据出处**：薪资/公司数据须标注来源（"据XX"），不编造、不夸大（通用黄金结构禁虚假宣传）。
- **匿名化**：非必要不点名具体公司；若需举例，用"某出海品牌"等。
- **立场声明**：行业判断留余地（"大概率/极难"），避免绝对化。

## 七、落地产出
智能体输出：按《脚本表格输出规范》的 **5 列竖版表**（`时长 / 画面镜头（竖版） / 口播台词 / 屏幕字幕 / 节奏·语气`）+ 钩子备选 + 合规提示，可直接进入拍摄。
- **内容方向、钩子选择、深版(90s+)结构、联网复核、自检**以《00_写作操作手册_整合版》为准。
- 时长档位：基础 35–55s / 标准 55–75s / **深度 80–120s**（联网复核到公司数据/行业趋势/舆论事件时扩展，每 8s 一个信息点 + 反转卡点）。

## 八、实习发展探索变体（MODEL-001 V2 实习岗研判：主线=发展探索，坑点轻带）
- 当岗位类型=实习岗，本模板切换为"发展探索"主线：**重心=这段实习能试出哪个正式方向 + 含金量 + 后续怎么走**，坑点只作注意项轻带。
- 钩子偏好：身份锁定 / 悬念提问 / 清单承诺（"这段实习值不值得冲""能往哪走"），避免纯反常识吐槽。
- 结构（深版示例）：钩子 → 共鸣 → 公司/赛道深挖（联网数据）→ JD 正向拆解（能蹭到的链路）→ 发展探索（3 个正式方向）→ 注意项（轻带坑）→ 风险/口碑（联网事件）→ 收口互动。
