# 脚本写作操作手册（整合版）

> 模块⑤ 的**权威写作手册**，是智能体产出脚本的"操作总纲"。
> 整合自《求职类爆款短视频脚本写作指引_聚焦版》（根目录原稿，本整合版为唯一执行口径）+ 本智能体既有 ST-002 / ST-003 / 输出规范，并新增三条硬要求：**① 时长分级（可加深）、② 全信息先联网复核、③ 实习/正职分方向**。
> 适用：ST-002 避坑型 / ST-003 高价值型 / 实习发展探索型；覆盖 5 大类泛商科岗。
> 写作铁律：求职类要爆，**不是讲道理，是给模板 + 戳痛点 + 造可复制话术**。

---

## 0. 生成前必做：方向判定 + 联网复核

每拿到一条 JD，先跑两步，再下笔：

**第一步 · 方向判定（引用 MODEL-001 V2 实习岗发展探索 / 四类型方向）**
- 范围：out_of_scope（医生/律师/公务员/程序员等强资质）→ 拒生成并说明范围外。
- 岗位类型：
  - **实习岗** → 主线=**发展探索**（高价值子型）：重心是"这段实习能帮你试出哪个正式方向、含金量、后续怎么走"，坑点只作"注意项"轻带，不做纯避坑吐槽。
  - **正职岗** → 按常规避坑 / 高价值走，重心=岗位本身分析 + 前景。
- 内容方向（结合⑥评分）：避坑典型 / 高价值 / 双线（避坑主+高价值副）。

**第二步 · 联网复核（硬要求）**
- 脚本中**每一个事实性断言**（公司数据、行业趋势、舆论事件、薪资基准、岗位前景、职业路径）都必须先联网检索，落地时标注来源与日期。
- 未核验的信息：要么不写，要么明确标「据公开信息 / 个人观点」，禁止当事实陈述。
- 产出物末尾必须附 **「信息核验表」**（事实 / 来源 / 检索日期 / 结论 / 置信度）。
- 模块①②③优先：先查 JD库 / 体验库 / 趋势库，库内不足再联网回填（与既有"先检索库→不足联网"机制一致）。

## 1. 时长分级模型（回应"案例太浅，可适当增加时长"）

| 档位 | 时长 | 适用 | 信息密度要求 |
|------|------|------|--------------|
| 基础版 | 35–55s | 单岗位单判断 + 1 个清单（JD 信息量小） | 每 10s 一个信息点 |
| 标准版 | 55–75s | 双线（避坑+高价值）/ 实习发展探索 | 每 8–10s 一个信息点 |
| **深度版** | **80–120s** | **联网复核到丰富素材（公司数据/行业趋势/舆论事件/职业路径）时必用** | 每 8s 一个信息点 + 1–2 个反转卡点 |
| 长拆解版 | 2–3min | 跨多岗位 / 行业深度 / 系列合集 | 分段小钩子维持完播 |

> 原则：时长可以加，但**密度不能掉**。深版不是"把话说慢"，是"多塞真东西"——每多 10s 必须多一个可验证的信息点、金句或反转。2026 算法看有效完播率，高价值段被反复拖看权重更高。

## 2. 时间轴工程学（每段都有使命）

| 时间轴 | 段落使命 | 求职类必做动作 |
|--------|----------|----------------|
| 0–3s | 钩子（黄金 3 秒） | 痛点 / 反常识 / 身份锁定，让用户舍不得划走 |
| 3–10s | 共鸣铺垫 | 一句话放大焦虑或场景，"说的就是我" |
| 10–30s | 干货主体 | 给判断 / 清单 / 话术（可复制，促收藏） |
| 30s–结尾 | 收口 + 互动 | 抛结论 + 评论区 / 收藏引导（互动权重约 40%）|

深版扩展：30–60s 放行业/公司深挖 + 第一个反转；60–90s 放职业路径/避坑注意 + 第二个反转；末段收口互动。

**关键原则**：中后段每 8–10s 一个"新信息点 / 反转 / 金句"，维持有效完播，别把所有干货堆开头。

## 3. 钩子库（开头 3 秒，必带 1 个；分方向选）

| 类型 | 模板 | 适用方向 | 示例 |
|------|------|----------|------|
| 痛点共鸣 | 「你是不是[人群]，[具体焦虑场景]？」 | 通用 | 「你是不是应届生，投了 200 份没人回？」 |
| 反常识 | 「[岗位] 看着[光鲜]，其实 [N] 类人进去就废」 | 避坑 | 「跨境电商看着自由，其实 3 类人进去就废」 |
| 数据冲击 | 「[岗位] 真实[薪酬/门槛]曝光：[数字]」 | 高价值 | 「用户运营真实月薪曝光：8 成在 6–9k」 |
| 身份锁定 | 「[人群] 别投 [岗位]，除非你能接受这 [N] 点」 | 避坑/实习 | 「25 届别投用户运营，除非你能接受这 3 点」 |
| 场景还原 | 「昨天有个[人群]问我：[问题]，我直接劝他…」 | 通用 | 「昨天粉丝问我品牌营销是不是比产品好，我劝他别冲动」 |
| 悬念提问 | 「[岗位] 能去吗？先看这 [N] 个信号」 | 高价值/实习 | 「拓竹 IMC 实习能冲吗？先看这 2 个信号」 |
| 清单承诺 | 「面试 [岗位]，背下这 [N] 句就不慌」 | 通用 | 「面试产品经理，背下这 5 句就不慌」 |

**实习岗钩子偏好**：身份锁定 / 悬念提问 / 清单承诺（"这段实习值不值得冲"/"能往哪走"），避免纯反常识吐槽。
**禁词规避**：小红书严禁"第一/最/绝对"，用"多数/头部之一/大概率"替代。

## 4. 正文怎么写：把 JD 变成爆款

**4.1 信息差挖掘**（从库字段出发）：调 `content_angles` 生成立意；从③趋势库取"扩招/缩招"做时效；从②体验库取"真实一天/后悔点"做避坑。

**4.2 六维评分 → 口语化翻译**（MODEL-001 V2，不念分数）：
- ❌「该岗发展维度评分 7.2」
- ✅「这岗发展上限其实不错（个人观点），但前提是你得熬过前两年执行期」
- 双方向句式：「值不值得去？[人群A]值得，[人群B]劝退（个人观点）」

**4.3 可复制话术 / 清单写法（收藏动机核心）**：正文至少给 1 个——清单（"面试 XX 岗 HR 最爱问 3 问+答案"）、话术（"谈薪直接说这 2 句，大概率多拿 1–2k"）、对照表（"A 岗 vs B 岗三行对比"）、流程（"从 0 到 offer 的 4 步"）。用"你直接抄/背下来/照着填"降低门槛。

**4.4 反转 / 金句卡点**：正文 1/3 处放一次反常识转折（"但真相是…"）拉回划走的人；最关键结论做成金句单独卡一顿（"记住一句话：…"）提升转发。

## 5. 完整填空骨架（深版 90s+，实习发展探索型为例）

```
【0-3s 钩子】[悬念/身份锁定]：[岗位] 能冲吗？先看这 2 个信号
【3-10s 共鸣】很多人只看薪资/招牌，忽略了[关键变量]
【10-25s 公司/赛道深挖】[联网复核数据：营收/份额/社区/新赛道] → 说明平台量级
【25-40s JD 正向拆解】支持传播/campaign/branding + 管资产 + 对接 agency → 你能蹭到的完整链路
【40-55s 发展探索·能往哪走】这段实习帮你试 3 个正式方向；毕业去哪投有话说
【55-70s 注意项（轻带坑）】偏执行协调；AI 提效压缩基础活，得抢核心；强度如何
【70-82s 风险/口碑】[联网复核舆论事件] → 做品牌的长心眼（个人观点）
【82-90s 收口互动】适合谁 + 评论区/收藏引导
```
深版每多一段都对应一个**已联网复核的信息点**，不是水时长。

## 6. 结尾互动设计库（互动权重约 40%，必带）

| 目的 | 台词变体 |
|------|----------|
| 评论 | 「你是什么专业/岗位？评论区说，我帮你判断」 |
| 评论 | 「你觉得这岗坑不坑？评论区吵一架」 |
| 收藏 | 「这份清单收藏好，投简历前对照一遍」 |
| 转发 | 「转发给正在找工作的朋友，帮他避个坑」 |
| 争议拉深 | 「有人说这岗没前途，我不同意，评论区见」 |

运营备注：发布后自占楼提问（"你是哪届？"）置顶干货补充，拉长评论深度。

## 7. 标题与封面文案（搜索词植入）

抖音/小红书大量流量来自搜索，标题与口播须自然埋高频词：岗位名、行业名、求职阶段词（应届/校招/转行/谈薪/实习）。

**标题模板**（含禁词规避）：
- 「[岗位] 真实经历：值不值得去，看完再投」
- 「面试 [岗位] 前，先搞懂这 [N] 件事」
- 「[人群] 转行 [岗位]，劝你先想清楚 [N] 点」
- 「[岗位] 招聘写的 vs 实际干的（附对照）」
- 禁词替换：「最值得」→「比较值得」；「绝对别去」→「大概率劝退」

封面：放**结论大字 + 1 个搜索词**（小红书识别封面文字收录）；抖音放"人物表情 + 结论"。

## 8. 节奏与完播（深版也适用）

- 反转设计：正文 1/3 处一次反常识转折。
- 信息密度：每 8–10s 一个信息点，深版可提到 8s。
- 金句卡点：最关键结论单独卡一顿。
- 口语化：用"你/咱们/说实话"拉近距离；短句、有网感。
- 去AI味（硬要求）：避免破折号（——）；避免「不是…而是…」「虽然…但是…」等套路句式；口播像真人聊天。

---

## 9. 合规内嵌写法（不破坏节奏，写进脚本）

1. **个人观点自然植入**：判断句后接「（个人观点，仅供参考）」。
2. **禁词替换表**：最/第一→多数/头部之一；绝对→大概率/基本；包进/保过/内推保过→禁用（涉虚假招聘/诈骗风险）。
3. **数据标注时效**：引用薪酬/份额/营收须加「据 [来源/年份]，仅供参考」。
4. **联网事实标注**：每个事实性断言在"信息核验表"标注来源与检索日期。
5. **不承诺结果**：只做政策/流程科普与概率判断，不替用户决定。
6. **out_of_scope 拦截**：强资质职业直接拒生成。
7. **无披露软广禁用**：涉及机构/课程须标「广告/合作」；商单/内推素材不得无披露复刻。

## 10. 自检清单（生成后必跑）

**算法友好（爆款潜力）**
- [ ] 前 3 秒有钩子，直戳求职痛点/焦虑？
- [ ] 标题/口播含 ≥2 个搜索关键词（岗位/行业/阶段）？
- [ ] 中后段每 8–10s 有信息增量（非前炸后水）？
- [ ] 至少 1 处"可复制模板/话术/清单"促收藏？
- [ ] 结尾有 ≥1 句评论区/收藏/转发引导？
- [ ] 有 1 次反转/金句卡点维持完播？
- [ ] 时长达到目标档位（深版 ≥80s）且密度不降？

**合规护栏**
- [ ] 无"最/第一/绝对/包进/保过/内推"等禁词？
- [ ] 判断类结论标「个人观点，仅供参考」？
- [ ] 数据标注来源与时效？
- [ ] 未无披露推广机构/课程？
- [ ] 强资质职业未误生成（out_of_scope 已拦截）？
- [ ] 无破折号、无「不是…而是…」套路句（去AI味）？

**联网复核**
- [ ] 每个事实性断言已在"信息核验表"标注来源+日期？
- [ ] 未核验信息已标「公开信息/个人观点」或不写？

## 11. 与 ST-002 / ST-003 / 输出规范的关系

- **ST-002（避坑）**：套本手册第 3 节钩子 + 第 4 节信息差/反转 + 第 5 节骨架（避坑变体）。
- **ST-003（高价值）**：套本手册第 3 节钩子 + 第 4 节行业洞察/可复制话术 + 第 5 节骨架（高价值变体）。
- **实习发展探索型**：套本手册第 0 步（V2 实习岗发展探索）+ 第 3 节实习偏好钩子 + 第 5 节深版骨架。
- **《脚本表格输出规范》**：决定最终 5 列竖版表呈现；本手册决定"内容与钩子方向 + 质量门槛"。
