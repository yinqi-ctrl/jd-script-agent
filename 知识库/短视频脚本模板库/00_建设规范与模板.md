# 短视频脚本模板库 · 建设规范与模板

> 模块定位：《这份工作能去吗？》职业探索类短视频内容策划智能体的**第⑤个核心知识库**。
> 作用：把"模块④ 爆款案例库"里抽象出的传播规律，落成**可套用的固定结构**，让智能体（短视频编导角色）按平台传播逻辑稳定产出脚本。
> 当前聚焦：**JD拆解/避坑型**单一模板（与频道招牌"这份工作能去吗"一致）。通用黄金结构作为底座，垂直模板在其上派生。
> 关联：模块④案例库（套路来源）→ 本库（模板）→ 下游脚本生成。

---

## 一、本库需要包含的信息字段
采用 **YAML frontmatter + Markdown 正文** 双结构，单个模板一文件。

| 组 | 字段 | 说明 |
|----|------|------|
| A 标识 | `template_id` | `ST-001` 起连续编号 |
| | `name` | 模板名，如"JD阅读理解/避坑拆解型 主模板" |
| | `type` | `通用` / `垂直` |
| | `based_on` | 来源案例 `case_id`（如 `["CASE-001","CASE-002"]`） |
| | `platform` | 适用平台 |
| | `duration` | 建议时长，如 `60s（可扩展）` |
| B 结构 | `structure` | 一句话结构摘要 |
| | `hook_types` | 可用钩子类型 |
| C 要素 | `tonality` | 口吻/人设（如"毒舌避坑·信息差·口语梗"） |
| | `must_include` | 必含模块 |
| | `avoid` | 禁止项（含合规） |
| D 关联 | `related_kb` | 关联案例/规则 |
| | `data_quality` | `A`=已验证可套用 / `B`=草稿 |

---

## 二、推荐数据来源
1. **模块④案例库**：从已验证爆款抽象结构（主来源）。
2. **通用短视频方法论**：平台创作学院、爆款拆解文章（你提供的"黄金结构"即此类）。
3. **自有复盘**：你账号高完播/高互动视频的结构回灌。

---

## 三、数据整理规范
1. **单模板一文件**：`短视频脚本模板库/<类型>_<名称>.md`。
2. **通用垫底、垂直派生**：每个垂直模板须注明"基于通用黄金结构 + 哪个案例套路"。
3. **可生成性优先**：模板必须含**占位符骨架**（如 `{{岗位}}`、`{{薪资区间}}`），智能体才能"填 JD → 出脚本"。
4. **口吻与边界同模板固化**：垂直模板必须带 `tonality` 与 `avoid`（合规），保证量产不飘、不踩雷。
5. **字段命名稳定**：frontmatter 字段定下后尽量不变。
6. **落地产出统一为竖版分镜表格**：最终脚本一律按《脚本表格输出规范》输出 5 列（时长/画面镜头竖版/口播台词/屏幕字幕/节奏·语气），ST-002/ST-003 均引用之。
