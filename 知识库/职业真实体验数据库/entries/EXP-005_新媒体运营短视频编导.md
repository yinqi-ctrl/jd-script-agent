# 职业基本信息
- **职业是什么**：负责账号内容生产、运营增长的人；编导偏策划/脚本/拍摄统筹，运营偏发布/数据/互动，小公司常一人全包。
- **大众印象**：刷手机就能赚钱、自由、紧跟潮流、门槛低、年轻人天堂。
- **实际工作定位**：内容流水线上的多面手+数据劳工；既要出创意又要扛指标，对"网感"和抗压的要求远高于对学历的要求。

# 真实工作状态
- **日常工作内容**：选题、写脚本、拍摄/剪辑、排版发布、盯数据、评论区互动、追热点、给老板汇报"为什么没爆"。
- **典型一天**：
  - 9:30 到岗，先刷热点和竞品；
  - 10:30-12:00 写脚本，被改两三版；
  - 14:00-18:00 拍摄+剪辑，老板随时要"再网感一点"；
  - 19:00 后 发稿盯数据、回评论，半夜追突发热点；
  - 周末常"随时待命"，数据差就是原罪。
- **高频任务**：写脚本、剪视频、看数据、追热点、改标题封面。
- **常用工具**：剪映/PR、飞书/钉钉、各平台后台、数据分析（新榜/蝉妈妈/灰豚）、AI 配图配音工具。
- **工作压力来源**：数据焦虑（播放/涨粉）、老板无标准返工、热点时效、一人多岗、AI 替代基础剪辑的危机感。

# 从业者反馈
- **常见优点**：入门快、创意能被看见、转行灵活、离生意近（懂流量=懂变现）。
- **常见缺点**：门槛低导致内卷、工资中位不高、加班无底线、指标悬顶、职业天花板模糊。
- **行业吐槽**："招聘恨不得一人包揽全流程""剪辑编导运营全员熬大夜，账号数据却原地踏步""数据差被骂，第二天还得笑着继续发"。
- **新人容易踩坑的地方**：
  1. 高估"自由"低估强度，以为不坐班就轻松；
  2. 只做执行不学数据分析，永远底薪；
  3. 被"全平台运营"JD 骗去干杂活；
  4. 忽视作品集，跳槽无筹码。

# 职业认知差
- **大众以为**：新媒体=轻松自由、玩着就把钱赚了、谁都能做。
- **实际情况**：入门极易但体感极苦——小公司一人多岗（文案+剪辑+运营+数据），半夜追热点、数据差就挨骂、无效加班来自需求模糊；中位收入并不高，"自由"往往等于"随时待命"。
