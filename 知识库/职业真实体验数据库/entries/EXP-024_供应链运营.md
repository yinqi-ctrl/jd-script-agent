# 供应链/工艺工程师（先进制造）· 真实体验（EXP-024）

## 一、职业基本信息
- **职业是什么**：在制造型企业负责供应链计划/工艺流程设计/现场改进的工程师岗。
- **大众印象**：工程师、实业、稳定、越老越香。
- **实际工作定位**：驻厂现场岗，连生产节奏、协调研发/采购/质量的"现场问题解决者"。

## 二、真实工作状态
- **日常工作内容**：巡线、处理异常、排产、跟物料、写工艺文件、成本核算、跨部门协调。
- **典型一天**：早会 → 产线巡线处理异常 → 排产跟料 → 写工艺/成本 → 协调会 → 加班随订单。
- **高频任务**：异常停机处理、排产、跟交付、写文件。
- **常用工具**：ERP/MRP、MES、Excel、CAD（部分）、精益工具。
- **工作压力来源**：交付节奏、产线异常、订单波动加班、跨部门扯皮。

## 三、从业者反馈
- **常见优点**：实业刚需、经验沉淀增值、新能源红利、转管理路径清晰。
- **常见缺点**：驻厂环境一般、产线节奏紧、加班随订单（部分岗位倒班/强度高）、扯皮消耗。
- **行业吐槽**："工厂里最累的是夹在研发和产线中间的工艺""订单来了连轴转，没订单也焦虑""驻厂没有写字楼的体面"（部分头部半导体厂流传"885"早8晚8一周5的高强度，属个例非全行业）。
- **新人容易踩坑**：低估驻厂环境落差；以为坐办公室；抗不住产线节奏与倒班；不善跨部门协调。

## 四、职业认知差
- **大众以为**：工程师体面稳定、越老越香。
- **实际情况**：驻厂现场为主、产线节奏紧、加班随订单，经验值钱但前期辛苦；新能源/头部厂红利明显但强度也高。

## 五、视频创作价值
- **避坑类**：驻厂环境与现实落差；倒班/高强度真相；跨部门扯皮。
- **揭秘类**：工艺/供应链工程师一天（产线现场）。
- **高价值类**：新能源制造红利与"越老越香"的真相。

> 注：以上为从业者聚合反馈，个体体验存在差异；创作时潜台词须标注"个人观点"，不做绝对化判断。
